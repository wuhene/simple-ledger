# Web 界面优化

状态：待用户验收 · 分支 `2026-11-24`

## 改动

- 首页把月份、结余、收入和支出放进同一个紧凑摘要。流水减小行距，优先显示备注，分类作为第二行。分类图标少量使用暖棕、紫、蓝和绿，深绿保留给主操作。
- 记账金额移到分类上方。分类按钮保留文字、图标和选中标记，数字键合成一个键盘面板。键盘右下角直接显示今天或所选月日，点开仍可使用日历、今天、昨天和手动输入。
- 保存先读取写入后的账本，再让记账页下滑。明细短暂标记新流水，保存反馈出现在返回页标题旁，避免挡住「记一笔」。补记跨月时明细跟随流水日期；从其他 Tab 打开记账仍返回原 Tab。
- 记账打开约 260ms，退出约 240ms，底层页面无需整屏淡入。主 Tab、月份和周期切换直接显示。系统开启减少动态效果时跳过记账转场。
- 统计合并日期导航和周期选择，收支切换、总额和日均同图表摆放，排行直接显示分类、金额和占比。
- AI 消息区独立滚动，输入区在底部；靠近最新位置时跟随新消息，查看旧消息时保留原滚动位置，并提供「回到最新」。普通回复减少背景装饰，保留草稿和统计卡。
- 餐饮固定显示在可见支出分类首位；如果已隐藏或缺失，记账页显示恢复或添加入口。内置分类采用 [Lucide](https://lucide.dev/icons/) 图标，购物、服饰、学习和书籍等识别更明确，沿用旧版备份键。许可见 [Lucide.txt](../../project/web/licenses/Lucide.txt)。

## 参考与验收

- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines)、[Anthropic Frontend Design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)。
- Chrome 360px、390px 验证日期补记、保存后最新流水、记一笔按钮可点、Tab 无切换动画、统计筛选、空会话的底部输入框和减少动态效果。
- 使用模拟模型验证长聊天里查看旧消息时不跳动，继续收回复后可点「回到最新」，并回归旧会话切换、刷新恢复和入账撤销。
- 用户可以重点复验首页显示密度、分类配色、数字键手感、日历切换、保存上下滑，以及聊天滚动。当前改动只在 Web 验收版。
