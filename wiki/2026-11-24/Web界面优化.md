# Web 界面优化

状态：待用户验收 · 分支 `2026-11-24`

## 改动

- 默认亮黄 `#FFDA44` 用于首页顶区、选中的底部 Tab 胶囊、中央记一笔、右下角 AI 入口、保存和发送。亮黄主题的底栏、统计标题和 AI 聊天标题使用白底。内置亮黄、浅青绿、浅雾蓝、浅灰紫、深墨绿和深墨蓝。通过「我的 → 设置与数据 → 外观主题」立即切换，按当前浏览器保存。
- 流水和排行分类图标采用深色轮廓和局部主题色填充。记账分类网格中，未选项一律显示浅灰圆底与无填色线稿，选中项加主题色和勾标识。

- 首页通栏顶部跟随主题，包含左对齐的月份和白色结余卡。卡内并列红色收入与绿色支出。流水区用白底和细线分隔日期分组，分组标题显示「今天」「昨天」或月日与星期，优先显示备注，分类作为第二行。
- 桌面验收画布采用细边框，并随窗口高度收缩以显示底栏；移动端继续占满可用高度。
- 打开「记一笔」时完整铺开当前收支类型的可用分类，列表可滚动，无默认选中。选择后底部出现带金额、备注、日期、数字键和保存按钮的区域。切换支出或收入时重新选分类；编辑已有流水保留原分类并直接显示输入区。
- 首页直接显示月份和账本，不再占用「简账」标题行。手动记账回到底栏中央；明细和统计的 AI 入口悬浮在右下，避开底栏。
- 保存先读取写入后的账本，再让记账页下滑。明细短暂标记新流水，保存反馈与流水笔数同排，其他返回页仍显示在标题旁。补记跨月时明细跟随流水日期；从其他 Tab 打开记账仍返回原 Tab。
- 记账打开约 260ms，退出约 240ms，底层页面无需整屏淡入。主 Tab、月份和周期切换直接显示。系统开启减少动态效果时跳过记账转场。
- 统计合并日期导航和周期选择，收支切换、总额和日均同图表摆放。趋势改用柱图，支出趋势和排行使用珊瑚色，可点击柱查看当天或当月数据，也可展开数据表。
- AI 消息区独立滚动，输入区在底部；靠近最新位置时跟随新消息，查看旧消息时保留原滚动位置，并提供「回到最新」。普通回复减少背景装饰，保留草稿和统计卡。
- 餐饮固定在支出首位，分类管理里不可隐藏或改名。打开旧账本或导入旧备份时，隐藏或缺失的餐饮自动修复，已有流水和分类 ID 保留。内置分类采用 [Lucide](https://lucide.dev/icons/) 图标，沿用旧版备份键。许可见 [Lucide.txt](../../project/web/licenses/Lucide.txt)。

## 参考与验收

- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines)、[Anthropic Frontend Design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)。
- Chrome 360px、390px 验证日期补记、保存后最新流水、记一笔按钮可点、Tab 无切换动画、统计筛选、空会话的底部输入框和减少动态效果。
- 使用模拟模型验证长聊天里查看旧消息时不跳动，继续收回复后可点「回到最新」，并回归旧会话切换、刷新恢复和入账撤销。
- 用户可以重点复验首页显示密度、分类配色、数字键手感、日历切换、保存上下滑，以及聊天滚动。当前改动只在 Web 验收版。
