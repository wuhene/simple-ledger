# AI 助手 PRD

需求分支 `2026-11-24` · 2026-11-24 · Web 待验收

## 目标与范围

让用户用自然语言新增一笔收入或支出，或查询账本统计。先用现有 Web 手机画布调试识别与交互，Web 验收后再确定 Android 实现和 API Key 保存方式。

首版支持单笔记账、金额追问、草稿编辑和撤销，以及指定某日、某月、某年和跨月区间的收支查询、分类排行和分类明细。保留手动记账、原统计页和原备份格式。批量入账、模型改删历史流水、跨会话聊天记录和其他模型协议以后再评估。

## 功能

| 功能 | 行为 |
| --- | --- |
| 对话入口 | 明细、统计右上角共用同一会话；保留现有底栏与中央「记一笔」。 |
| 记账草稿 | 「今天中午吃叉烧饭花了28元」生成支出 28 元、餐饮、今天、备注叉烧饭。允许修改金额、日期、分类和备注，确认才写本地账本。 |
| 不完整或不确定 | 缺金额时追问；分类匹配不上时留空给用户选；遇到歧义时提示明确问题，不直接写入账本。 |
| 防重与撤销 | 同时只能确认一次草稿。入账回执按时间进入聊天，可在相应回执撤销；已在其他页面编辑的流水由明细处理。 |
| 统计 | 日期区间含首尾，正在发生的周期算到今天。读已有账本、用整数分汇总，显示实际起止日期、收支、排行和占比。无记录显示空态，金额并列时列出并列类别。 |
| 追问与下钻 | 统计卡按发送顺序留在聊天里，保留查询时的结果。统计后可继续问上个月或某分类，也可点旧卡片查看该区间最近 20 条。 |
| 新会话 | 从聊天顶部开启，清空当前对话和识别上下文，保留已入账流水及模型配置。若有未确认草稿，需确认丢弃。 |
| AI 助手设置 | 「我的 → 设置与数据 → AI 助手设置」，聊天页也可快捷进入。包含 API 地址、模型 ID、API Key、同意发送、保存、测试连接和清除配置。 |
| 连接测试 | 用固定的虚构午餐请求测试地址、模型和返回格式。结果正常时提示连接成功，鉴权、额度、超时、格式问题显示对应提示。 |

## 数据与模型

- 配置并同意后，每条消息都由用户选定的模型识别。模型返回记账草稿、统计条件、追问或简短回复。完整规则见 [系统提示词](AI助手-系统提示词.md)。
- 模型输入限本次消息、当天日期、最近一次查询条件及必要的未完成追问。现有流水、统计金额与备份不作为模型输入。
- Web 调试版设置和 Key 只保存在当前页面内存。网页刷新后需重新配置，「新会话」保留当前配置。Key 不纳入浏览器持久化、账本备份或源码。调试服务仅绑定本机。

## 验收

在 360px 和 390px 下确认对话、草稿与设置可用。用测试账本验收金额追问、草稿确认、防重撤销、跨月合计、旧卡片留存和新会话清理上下文。真实模型联调需选定服务商、提供可用的 API 地址和模型 ID，并在本机配置凭证。
