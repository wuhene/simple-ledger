# 简账二版 · UI 与动效设计文档

版本：2.0 设计稿 · 2026-09-30 · 状态：待验收

配套：[二版 PRD](二版-PRD.md) · [静态视觉稿](二版-UI视觉稿.svg) · [设计参考](设计参考.md)

## 1. 视觉方向

关键词：温润、清晰、安静、有回应。保持初版森林绿主色，用暖白页面、浅绿容器、少量杏色提示增加层次。首页以月结余和流水为视觉中心，功能按钮形成稳定的操作层级。使用细线图标和细微层次，不借渐变、厚阴影、密集圆角卡片营造“精致”。

二版保留四个底部导航：明细、统计、工具、我的；不改变 P01—P14 页面信息架构。视觉稿以 390×844 手机为基准，三屏分别展示首页、记账日期弹层、记账页，数据仅作布局示意。

## 3. 页面与组件规格

### 3.1 首页（P01）

布局由上到下：安全区 → 顶栏（“简账”、金额显隐）→ 年月导航 → 月概览 → 本月明细标题和计数 → 日期分组列表 → 悬浮记账按钮 → 底部导航。顶栏不堆叠功能入口。

年月导航高度 48dp。年月按钮文字“2026 年 9 月”，带下拉符号；左右圆角图标按钮至少 48dp 触控范围。切到未来月仍显示空账单，但悬浮记账按钮新增日期仍默认今天。

月概览为白色 20dp 圆角卡片，顶部小字“本月结余”，主金额占最高视觉权重，收入/支出放底部浅绿区域并明确标签。负结余保留负号与“结余”标签，不将整卡染红。列表日期标题一行展示“9 月 28 日 · 周一”和日支出/收入小计；记录行显示 40dp 图标容器、分类、单行备注、右对齐金额。行高有备注约 72dp、无备注约 60dp。

悬浮记账按钮为“＋ 记一笔”，高 52dp、水平内边距 18dp、离底栏 16dp、离右侧 20dp。滚动时保持可见；列表底部留出足够空间避免最后一行被遮挡。

### 3.2 日期选择器

统一视觉：圆角 24dp 白色底部弹层、顶部 4×36dp 拖柄、左标题右关闭、明确的“取消/确定”底部操作。记账日期弹层最大高度为可视区 85%；内容可滚动而操作按钮固定可见。首页选年月使用较矮的同款弹层。

**记账日历：** 顶部展示预选日期与星期；“今天”“昨天”快捷按钮；月份标题及前后月按钮；周标题从周一到周日；7 列日期格，每格最小触控 48×48dp，视觉数字居中。月前后留白格不占用可点击日期。今天以描边圆表示，选中以品牌绿实心圆＋白字表示；两者重合时选中圆下加小杏色点。未来日期和 1900 年以前日期弱化且无点击反应。非本月日期不作为可点击补位。

顶部年份/月份按钮打开快捷跳转子层，按年后选月；支持逐年切换及直接输入日期。输入模式明确格式 `YYYY-MM-DD`，实时显示“日期不存在”“不能晚于今天”“最早可记 1900-01-01”等错误。切换日历/输入模式保留合法预选值；无效输入不能确定。

点击日只改变弹层预选状态，确认后才写回表单。取消、遮罩点击、系统返回都恢复原日期。系统输入法出现时日历内容可滚动，底部确定键在可见区域内。

**首页年月弹层：** 顶部显示选中年份，主体 3×4 月份网格，当前月用细描边识别，待选月用品牌绿填充；“查看此月”提交。未来月份允许查看，年份范围 1900 至 9999，翻年按钮在边界禁用。

### 3.3 记账页（P02）

页面顶栏“取消 / 记一笔”；下方收支分段控件高 44dp，选中块填充白色并有极浅阴影，轨道浅绿。分类网格优先 4 列×2 行，名称在图标下，选中分类的图标容器为浅绿、有小勾标记，文字加重；“全部分类”与“管理分类”放网格后，不能伪装成类别。

金额区为主焦点：顶部“支出金额 / 收入金额”小标签，中间大号等宽数字/表达式；右侧无清空按钮，删除使用键盘退格以降低误触。金额右边不插入促销或次级动作。金额区下方日期、备注两行，分别使用统一线性日历、编辑图标；日期呈完整日期与星期，非今天显示“补记”小标签。

底部自定义金额键盘使用 4 列，沿用初版键位：`7 8 9 ⌫` / `4 5 6 ＋` / `1 2 3 −` / `清空 0 . 今天`。运算与日期快捷键使用浅绿底，与数字键区分；按键可见高度不低于 48dp，横向间距约 8dp，纵向约 2–6dp。主保存按钮独占底部一行，高 56dp，显示“保存记录”；保存中保留相同宽度，文字替换为“保存中…”。系统键盘弹出时金额键盘隐藏，页面滚动确保字段与保存按钮可达。取消仍遵循草稿确认规则。

### 3.4 按钮体系

| 级别 | 外观/尺寸 | 用途 | 状态 |
|---|---|---|---|
| 主按钮 | 品牌绿实心、白字、高 52–56dp、14dp 圆角 | 保存记录、日历确定、关键确认；一个视图只设一个 | 按下变深并缩小至 0.98；禁用浅绿灰；加载保留尺寸并加进度符号 |
| 次按钮 | `surfaceSoft` 底、品牌绿文字/图标、高 ≥44dp | 今天、昨天、查看月份等辅助操作 | 按下底色加深；选中有描边或勾选 |
| 文字按钮 | 透明底、主文字或品牌绿、触控 ≥48dp | 取消、全部分类、管理分类 | 按下有轻底色；危险文字用 danger |
| 图标按钮 | 图标 20–24dp，触控 48dp | 翻月、关闭、金额显隐、返回 | 必须有读屏名称与按下底色 |
| 悬浮按钮 | 品牌绿、图标＋文字、高 52dp、全圆角 | 统一“记一笔”入口 | 按下反馈，转场到记账页 |

同屏主按钮优先为“保存/确定”；“取消”不能与主按钮相同填充。危险操作用独立位置和确认步骤。禁用状态不只降低透明度，文字仍须可辨。按钮标签用动作结果，不用“完成”这种模糊词。

### 3.5 底部导航与统计

底部导航四项，图标 24dp＋12sp 标签；选中项有浅绿圆角背景、品牌绿图标和粗一点的标签。非选中项为深灰文字，不能完全淡化。导航高约 72dp＋系统安全区。统计页保留收支和周/月/年分段，新增层次：范围控件与主要金额间距 16dp，趋势图与排行各自有清楚标题，避免相邻卡片都带强阴影。

## 4. 动效时间表

以下数值是简账二版的设计目标，非外部规范的硬性数值；实现时允许按平台手感微调，交互顺序与减少动态效果要求不变。

| 事件 | 动画 | 时长/曲线 | 完成状态 |
|---|---|---|---|
| 按钮按下 | 缩放至 0.98、底色加深；释放回弹 | 90–120ms / ease-out | 操作反馈即时，不延迟业务执行 |
| 分类选择 | 图标容器缩至 0.96 再回 1.0；选中底色淡入 | 140–180ms / ease-out | 勾和文字同步更新 |
| 收支分段 | 选中块平移；网格旧内容淡出，新内容淡入 | 180–220ms / ease-in-out | 草稿金额/日期保持不变 |
| 底部导航 | 图标/标签 120ms；内容淡出→淡入 | 总 180–220ms / ease-out | 每页滚动与周期状态保留 |
| 首页换月 | 标题和列表朝方向平移 8–12dp＋淡入 | 180–240ms / ease-out | 数据准备好再替换，防错月闪烁 |
| 日历弹层 | 遮罩淡入，面板自底部上移约 24dp | 220–260ms / ease-out | 焦点进入弹层，背景不可操作 |
| 记账入口 | FAB 容器扩展为记账页主区域，内容随后淡入 | 240–300ms / ease-out | 无法执行容器变形时退化为淡入 |
| 保存成功 | 按钮出现确认图标，页面退回来源并给简短提示 | 确认 180ms；退出 180–240ms | 以持久化成功为触发，不提前成功 |
| 错误 | 输入框边线与文案显现，无抖动 | 120–160ms / ease-out | 读屏宣布具体错误 |

连续操作：动画可中断，最新目标优先；快速连点不会排队播放多段转场。数值和数据范围同时更新；动画结束后焦点落在新页面标题或相关字段。

`prefers-reduced-motion: reduce` 和 Android 减少动态效果开启时，取消位移、缩放、容器变形，状态可用 0–80ms 淡化或即时更新。页面不以动画作为唯一反馈；“已保存”和选中标记始终可见。

## 5. 适配与验收图例

390×844 为视觉稿，360dp 为小屏检查基准；320–480dp 竖屏均需可用。200% 字体放大时，金额和按钮不裁切，日期行可换行，记账页整体可滚动，保存按钮持续可达。横屏优先保持字段顺序和操作可达。图标统一使用 2dp 左右描边、圆头圆角，避免 Unicode 字符在不同设备变形。

| 场景 | UI 检查点 |
|---|---|
| 首次空账 | 月概览显示 0，列表空态文字和主记账入口可见 |
| 历史空月 | 日期仍可切换，写“这个月暂无记录” |
| 隐藏金额 | 金额以遮罩字符显示，读屏不朗读原金额 |
| 负结余/超支 | 明确负号与标签，颜色仅作辅助 |
| 日历今天且已选 | 品牌绿选中圆、小点表示今天；读屏含“今天、已选中” |
| 输入非法日期 | 保持弹层，显示错误和有效范围，确认不可操作 |
| 保存失败 | 草稿原样保留，错误就近显示，按钮可再次尝试 |
| 删除撤销 | 原详情退出、短提示含“撤销”，5 秒内可操作 |

参考资料的选择理由见[设计参考](设计参考.md)。视觉稿只表达结构、样式与代表性状态，具体功能以 PRD 为准。
