调研时间：2026-09-30。以下链接均为产品或平台的一手资料；借鉴交互原则和组件组织，不直接复制品牌视觉或界面素材。

| 来源 | 观察到的做法 | 简账二版的应用与取舍 |
|---|---|---|

| [Android Developers · MaterialDatePicker](https://developer.android.com/reference/com/google/android/material/datepicker/MaterialDatePicker) | 选择器有标题、日历/输入模式与确认/取消动作。 | 日历选择采用“预选→确定提交”；取消、关闭与系统返回均保留原表单日期。 |
| [Android Developers · Buttons](https://developer.android.com/develop/ui/compose/quick-guides/content/create-button) | 按钮形态存在主要、次要及文字等层级。 | 保存/确定用实心主按钮；快捷日期用浅色次按钮；取消用文字按钮，避免所有动作抢同一视觉权重。 |
| [Android Developers · Material motion](https://developer.android.com/codelabs/material-motion-android) | Container Transform、Shared Axis、Fade Through、Fade 用于表达容器变化、层级与页面切换。 | 记账 FAB 入口参考容器变化，底部标签参考淡出淡入，月切换参考方向性位移。动效时长由本项目定义。 |
| [Android Developers · Navigation bar](https://developer.android.com/develop/ui/compose/components/navigation-bar) | 紧凑屏幕的底部导航适用于 3–5 个顶级目的地，选中项有明确图标与标签。 | 保留明细、统计、工具、我的四个顶级目的地，选中底色、文字及图标同步变化。 |
| [Money Manager · Home tab](https://help.realbyteapps.com/hc/en-us/articles/360043325533-Home-tab) | 账目可按日历/月/周查看，点日期可浏览当天详情并添加记录。 | 首页月份入口与记账日期入口都保持可发现；简账不复制其信息密度，保留“月概览＋按天流水”的清晰主线。 |
| [Money Manager · product screenshots](https://www.realbyteapps.com/iphone.html) | 财务数据、日历和图表有多个视图，用于切换总览与明细。 | 日历布局优先保证快速定位，统计仍保持初版范围与数据口径，不因为界面优化新增复杂报表。 |
| [MDN · prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/prefers-reduced-motion) | Web 可根据用户的减少动态效果偏好调整非必要动画。 | Web 后续实现提供减少动效分支；原生阶段接入系统对应偏好，取消明显的位移、缩放与容器变形。 |
