## 顺序与依据

用户再次确认：先在 Web 端查看和验收效果，确认后才转写为原生 Android 并打包 APK。本分支从最新 `master` 创建，并合入待验收的 `2026-09-30-1` 作为 Web 二版基线；两者均未合入 `master`。业务规则沿用初版 PRD，二版视觉与交互以 `wiki/2026-09-30-1/` 为准。

## 本分支待办

1. 补验 Web 二版在小屏、放大字体和减少动态效果下的可用性；修复实际遮挡和横向溢出。
2. 用 10 年/10 万笔数据测量 Web 的冷启动、月明细与统计响应；记录设备/浏览器/数据分布，按证据优化。
3. 保持记账日期键、日历取消/确认、账务计算及 IndexedDB 行为，回归初版业务测试。
4. 提供可重启的本地 Web 预览说明，提交并推送供用户验收。

原生 Android、APK 与真机验证维持待办，须在 Web 版验收后开始。Android SDK 构建工具已预装在被 Git 忽略的 `.tools/`，不代表原生开发已开始。旧软件导入仍缺实际导出样本；云同步、多账本和账户明细不在本需求范围。
