# 私人账本安装与模型配置

## 0.2.8 验收反馈

- 手动记账选地点时保留原备注，地点另起一行。再次选择同一个地点不重复追加。达到备注上限时保留现有文字，并提示可缩短后重新选择。
- 桌面和启动器显示「爱记账」。含数据的安装包沿用 0.2.7 的应用 ID 和签名，可以覆盖安装，首次加载标记也沿用原值。
- Web 17 项测试通过，Chrome 验证换行保存、重复选择和 200 字上限。Android 模拟器验证已有备注与地点同时保留、重新选择去重和 SQLite 中保存真实换行。覆盖升级后原账本流水笔数保持一致。

- 私人安装版使用独立包名 `com.wuhene.simpleledger.privateledger`。首次启动仅对空库导入本机传入的分月 ZIP，完成后写入标记，覆盖安装时保留账本。普通版和合成数据验收版继续使用各自包名。
- 在仓库根目录执行 `./project/android/build-debug.ps1 -PrivateLedgerArchive <本机分月备份ZIP>`。安装包输出到被 Git 忽略的 `project/android/app/build/manual-private/AiLedger-private.apk`。真实账单、备份 ZIP、私人 APK、模型密钥均不进入 Git。普通构建不使用私人资产目录。
- 原始账单日期、收支类型、分类、金额和备注优先。日期区间补标的地区使用 `省份` 或 `城市`，另留地点来源。只有账单日期的导入行使用稳定的同日顺序，入账小时排行跳过这类记录。省份查询可带或省略「省」后缀。
- Android 0.2.7 将模型地址与 ID 持久化到应用私有偏好，API Key 由 Android Keystore 加密。测试连接使用临时配置，「保存设置」才覆盖已保存配置，「清除配置」会删除持久化副本。模型配置独立于账本 ZIP 和其他安装包。旧版本只在内存中保留配置，升级后首次需要重新保存。

## 验收

- 对照原始导出校验笔数、收入／支出合计、日期、分类与备注。检查地名区间边界、未标位置行、坐标缺失和按省／市精确筛选。
- 签名校验后检查私人 APK 的资产仅有私人备份与应用运行资源。检查普通 APK 不含任一内置流水。
- 在模拟器首次安装验证真实账本入库。使用本机要求认证的测试端点，验证退出进程后仍可恢复配置和解密密钥、测试连接，以及清除配置后再启动仍为空。
- Web 16 项测试通过。普通与私人 APK 均通过 v2/v3 签名校验。Android 35 模拟器验证首次导入、原始收支合计、日期边界与地区索引。模型测试端点在强制停止后仍收到已保存的密钥，清除配置后重启保持为空。
