- 环境：Windows，本地 JDK 17.0.20.1、Android SDK 35、Build Tools 35.0.0。Gradle 8.13 启动被本机 Java 本地套接字错误阻断（`Unable to establish loopback connection`）；改用仓库内 `project/android/build-debug.ps1` 直接调用 `javac`、`aapt2`、`d8`、`zipalign` 和 `apksigner`，完整构建成功。Gradle 工程及 Wrapper 仍保留供标准 Android Studio 环境使用。
- `LedgerMath` JVM 冒烟测试通过：`18.50+3−2=19.50`、金额上限、零/三位小数/负结果/未完成表达式拒绝、闰日及跨年切月。
- APK：`com.wuhene.simpleledger`，`versionCode=1`，`versionName=0.1.0`，最低 API 26、目标 API 35；签名 v2/v3 验证通过。SHA-256：`FC4F6FE230C1BAAC3C1110FEA867A661D98AFA345C0958D7FFCA1BA550F14D3A`。
- 尝试安装 Android 35 x86_64 模拟器镜像并创建 AVD；启动提示 `x86_64 emulation currently requires hardware acceleration`，本机未安装 Android Emulator hypervisor driver，因此没有设备安装和运行结论。
- 统一目录后，在 `project/web/` 执行 `npm test`：5 项通过；`node --check app.js` 通过。Android APK 文件未改动，哈希保持上述值。

## 设备验收清单

1. 安装 APK，新增支出 `18.50+3−2`，检查明细、统计、月预算和报告均显示 19.50 元；编辑跨月后两个月汇总同步变化。
2. 在记账页输入草稿后用系统侧滑或返回键：先看到放弃确认，选择继续填写后草稿保留；无草稿直接下滑返回。日期弹层取消不改日期，点“今天”可快速恢复今天。
3. 检查四主导航、账单月/年下钻、分类隐藏与历史记录、金额隐藏、预算与资产、JSON 导出/恢复/清空、报告预览与系统分享。
4. 在目标设备检查 320dp 小屏、系统大字号、安全区及 10 年/10 万笔导入后的启动和统计速度。旧软件数据导入仍需样本。

Debug 签名密钥仅保存在本机被忽略的 `.tools/debug.keystore`；换机器重新构建的调试包可能不能覆盖安装。更新前先导出 JSON 备份。用户要求的目录统一会把源码整合到 `master`，设备功能验收和性能验证仍保持待验证。
