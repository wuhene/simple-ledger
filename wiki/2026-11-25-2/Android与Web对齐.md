# 爱记账 Android 0.2.1

分支 `2026-11-25-2`。参考已接受的 Web 工作版本 `2c9e7ad`，结合 `2026-10-10-1` 的 Android 返回与动效要求。真机待验收。

## 预置 10 万笔验收数据

- [独立验收 APK](../../project/android/AiLedger-acceptance.apk) 安装后显示为「爱记账」，应用 ID 为 `com.wuhene.simpleledger.acceptance`。首次打开会显示载入提示，完成后在「我的」核对总笔数 100,000。可与原应用并存，各自使用独立账本。
- 数据覆盖 2011-11-26 至 2026-11-25，共 181 个账期月份。流水标注「【压测】」。搜索「四季民福 烤鸭」或让 AI 查询北京吃过的四季民福烤鸭，可用预置的 2,000 笔记录验收。样本收入合计 5,499,600 元，支出 6,893,900 元。
- [普通升级 APK](../../project/android/SimpleLedger-debug.apk) 沿用原应用 ID 和本地数据。现有安装需与新包签名一致才可覆盖升级。预置数据, 预算和资产只在独立验收包首次打开时加载。
- 已校验两个 APK 的签名和显示名，已确认验收 APK 包内含 ZIP，桌面解析及索引匹配通过。首次真机启动的导入耗时待测。

## 范围和验收清单

| 页面或能力 | 真机操作和预期 |
|---|---|
| 首页、主题和底栏 | 默认亮黄顶部、白底流水，头部收入红、支出绿。核对底部「记一笔」、右下 AI 入口、六套主题切换和重新打开后的主题。 |
| 手势跨月 | 当月流水滑到底后再向上推，进入上月月初。上月滚回顶部后向下拉，返回新一点的月份底部。单次手势只跨一个月，月份箭头和选择器仍可用。 |
| 手动记账 | 打开记账卡从底部滑入，无默认选中分类。餐饮在第一位，点选后才显示数字键盘并填色。点日期键可选今天、昨天和过去日期。保存或系统返回让卡片下滑。保存后底页金额和流水更新。 |
| 定位和详情 | 手动点「添加定位」触发系统权限。拒绝后仍可保存。确认后详情显示坐标和精度。改变业务日期或手动移除后位置清空。补记地点可写进备注。 |
| 编辑、删除与撤销 | 编辑保存后在正确账期显示。删除后五秒内可撤销。当天按创建时间倒序。编辑、跨月、删除与撤销应同时影响搜索、金额和月账单。 |
| 分类管理 | 收支分组、显示和隐藏、自定义名称和图标、长按拖动排序。餐饮固定置顶可用。历史流水仍可显示已隐藏的分类。 |
| 统计和工具 | 统计切换按周／月／年和收入／支出，查看柱图数据、分类排行及明细。查看月账单、年账单、预算和资产，预览报告并用系统面板保存 PNG 或分享。 |
| AI 模型和记账 | 在设置填兼容接口地址、模型 ID、Key，测试后保存或清除。说「今天中午吃叉烧饭花了28元」，核对草稿、编辑线索、确认以及撤销。打开新会话后从历史回到先前对话。 |
| AI 查询和追问 | 从历史找「北京吃的烤鸭」，核对餐饮前 10 笔金额降序及每条完整年份。先查两个结果再要求展开第一张，核对范围和上下文。卡片留在对应回复，模型也可单独回复文字建议。 |
| 备份和恢复 | 导出 ZIP 和兼容 JSON，读取预览，确认后恢复。用 Web 备份核对备注、原话、线索、位置、分类、预算和资产。恢复会替换当前账本，先导出要保留的账本。 |
| 老版升级 | 同签名覆盖安装可沿用现有数据库，首次打开重建旧记录的索引。真机建议保留可恢复的旧版备份。 |

## 实现与验证

- 原生 Android View 负责界面及动画，Android 系统提供返回手势、输入法、定位授权和文件选择。使用 `project/android/build-debug.ps1` 构建可安装 APK。
- SQLite 流水按业务日期建立索引，文本单字和双字倒排项带日期，可用开放线索精确匹配。增删改事务更新词元和月汇总。每月 ZIP 分片有 SHA-256，兼容既有 JSON。兼容备份上限 12 万条，两端一致。
- 桌面 JVM 运行 Android 的备份解析和检索代码，验证 Web 生成的 100,000 笔、181 个月数据。跨年按城市与两个关键词命中 2,000 笔，两端合计收入 509,600.00 元、支出 4,544,400.00 元，错误分类引用被拒绝。另用桌面 SQLite 执行 Android 架构和触发器，校验汇总、跨月改动和删除后的词元清理。
- SDK 35 构建通过，包名 `com.wuhene.simpleledger`，最低 SDK 26，签名验证 v2/v3 通过。Web 的 10 项 Node 测试通过。
- 本机没有连接设备，可用模拟器未启动。设备安装、系统交互、显示、模型连接、定位和 10 万笔设备性能均待用户确认。APK 的系统原生控件样式和系统交互按设备表现验收。
