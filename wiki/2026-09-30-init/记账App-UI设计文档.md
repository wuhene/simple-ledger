# 简账 · Android UI / UX 设计文档

版本 1.0 · 2026-09-30 · 配套《记账App-PRD》与《记账App-交互原型.html》

## 1. 设计方向

浅灰白背景、白色内容层、低饱和森林绿强调色。视觉中心是金额和分类，不是品牌色大面积铺底。取消截图里全屏黄色顶栏、绑定手机横幅、悬浮分享遮挡和会员推广。保留分类网格和加减键盘这些高效率操作。

布局遵循：每屏一个主任务；数字比描述更突出；导航和工具分层；统计中的不同色彩只用于分类识别。首页卡片少而清楚，普通列表依靠留白和细分隔线，不给每一行套阴影。

## 3. Android 布局与适配

以宽360dp / 390dp作为主设计基准，不把HTML像素直接当作原生dp。支持320—480dp竖屏；平板居中内容最大宽600dp。状态栏使用浅底深色图标，导航手势区域保留系统安全区。工具栏56dp，底部导航约72dp加系统底部安全区；悬浮记账按钮距底部导航16dp、距右侧20dp。

系统字体放大到200%时，收支三列变为纵向或两行，卡片随内容增长；按钮保持触控面积，不能裁掉保存键。横屏允许滚动，记账页分类与输入上下滚动或分栏，优先保证输入区和保存键可达。

原型模拟390px手机画布，桌面左侧页面目录仅用于设计评审，Android产品不出现该目录。原型浏览器以100%字号演示；无障碍适配需要Android实现阶段按本规范完成。

## 4. 页面规格

### P01 明细首页

顶栏左侧“简账”，右侧金额显隐按钮；第二行年月和前后月。收支概览卡：小标题“本月结余”，主金额，底部左右“收入/支出”。结余为负时带负号，仍是同一布局。

下方“本月明细”与记录数，按日期分组，组头显示当天收支小计。分类图标置于40dp浅色圆角容器，分类名左对齐，金额右对齐，备注在分类名下方。滚动时顶部日期控件保持可访问，不需要整张金额卡一直占据屏幕。

右下“＋记一笔”带文字悬浮按钮。点击行到详情，不在行右侧常驻删除图标。空态放简短文案和“记第一笔”。隐藏金额用“••••”，保留正负类型标签，但分享前重新让用户确认是否包含金额。

### P02 记账/编辑

顶栏左“取消/返回”，中“记一笔/编辑记录”，收支分段控件。上半区为4列分类网格：默认优先展示前8个分类，“全部分类”展开列表；选中为浅绿容器+绿色图标+选中标记。分类管理用文字入口，避免混进分类网格当成类别。

金额区在分类下方，显示“支出金额/收入金额”，大号金额或计算式。日期与备注位于金额下方，日期字段必须有日历图标和完整日期。底部为自定义金额键盘：数字区3列，右侧独立运算/日期快捷区，保存键占底部完整宽度。正文输入弹系统键盘时金额键盘隐藏。

错误在对应区域内联显示，金额异常不只用瞬时Toast。保存中显示“保存中…”禁用重复点击。编辑界面复用此布局，删除放详情页，避免数字键盘旁误触。

### P03 详情 / P05 分类明细

详情页主金额居中；以下为类型、分类、日期、备注标签值，备注允许换行。底部“编辑记录”为主要按钮，“删除记录”为独立红色文字按钮。删除确认显示分类、金额、日期。

分类明细顶栏“住房”，副标题继承“2026年9月 · 支出”；显示分类总额、笔数、周期占比，下面复用日分组明细。空态返回统计时保留原周期。

### P04 统计

顶部收入/支出分段，下面周/月/年分段及当前周期前后箭头。总金额32sp，日均辅助信息。趋势折线高度160dp，使用轻网格，横轴最多6个标签，实际日点不强行全部标文字。触摸点显示浮层，包含日期和金额；提供图表数据列表入口，读屏可获取数据。

分类排行每行：图标、名称、金额；第二行比例与细进度条。圆环不重复塞进主统计页，放报告里表示组成。排行条采用同类同色，点击整行下钻。零数据时图表区域写“这个周期暂无支出”，禁用不存在的点选择。

### P06 工具

账单大卡展示选定月的收支结余，整卡可点，右箭头提示下钻。预算卡展示金额和线性进度而非大圆环：未设置时一句文案+按钮；正常显示“剩余 ¥…”；超支显示“已超支 ¥…”。资产卡展示净资产，资产/负债辅助列；未维护时显示“填写资产与负债”。

没有“推荐”、轮播、消息红点和运营内容。工具页三个区块足够。

### P07 账单列表

顶栏“账单”，月账单/年账单分段。月模式提供年份选择；概览卡为该年结余，副列为收入/支出。表头“月份/收入/支出/结余”，金额等宽数字、右对齐；320dp或大字模式改为每月一行两段标签，不横向裁切。当前月标“本月至今”。年模式用“年份”替代“月份”，顶部为累计结余。

### P08 月报告 / P09 年报告

白色标题栏“2026年9月账单”，分享放顶栏可见按钮，不悬浮在内容上。概览卡收支结余和对比口径。支出组成：左圆环、右金额与简短图例；下方完整类别列表。负结余不使用喜庆背景。

长报告分为可扫描的小节：组成、单笔排行、支出趋势、近6月对比、类别变化、收入、成就。主指标集中在对应图表上方；每张图都有单位，精确金额在标签/详情中，不用只显示“2万”掩盖精度。短横柱比彩虹柱更适合分类排行。

近6月柱图突出当前月，其余降低饱和度，减少无意义颜色；变化前三使用“增加/减少”文字，避免仅画红箭头。分享按钮点击进入内容确认与图片预览，默认不包含私密备注。

年报告复用概览、12月趋势、分类表，不把月份排行换个标题当成年报告。

### P10 月预算

标题含年月，展示已用/剩余。输入区域说明“月总预算”，数字键盘，按钮“保存预算”。编辑时可删预算。超支色只用于超支数字与状态，整页不铺红。新月未设置不自动显示上月预算。

### P11 资产

净资产主卡，资产和负债两列；下面“编辑资产概览”。弹出输入表单包含资产总额、负债总额、保存按钮；不提供“收入/支出”选项。底部明确手动维护说明和更新时间。未设置时不展示伪造零值。

### P12 我的

头像不要求真实照片，初始可用单色“账”标。成就横向三项“连续记账/记账天数/总笔数”，字号20sp，不搞打卡奖励。下面分组列表：分类管理、设置与数据、使用说明、关于。不显示VIP、积分、邀请、评级入口。

### P13 分类管理

顶部支出/收入分段；行含图标、名称、隐藏状态、排序拖柄；右上“新增”。隐藏项在底部“已隐藏”可折叠区域恢复。改名弹窗字段校验；删除历史引用分类时只提供隐藏操作并解释“历史记录将保留”。

### P14 设置与数据

金额默认隐藏开关；导出备份、从备份恢复；使用说明；关于。清空数据放在单独底部危险区域。恢复预览显示记录笔数、日期范围和预算数量，确认“替换当前数据”，不得设计成一个无提示的导入按钮。

## 5. 通用交互与反馈

| 组件/状态 | 规范 |
|---|---|
| 页面切换 | 150–220ms轻淡入/位移；遵循系统减少动画设置 |
| 分段控件 | 浅灰轨道、白/浅绿选中块、文本选中态；不只靠下划线 |
| Toast | 仅用于已保存/已撤销等轻反馈；重要错误内联显示 |
| 底部弹层 | 最大屏高85%，拖柄、标题、明确关闭；长内容可滚动 |
| 返回 | 关键盘→关弹层→返回页；草稿有变化提示放弃 |
| 占位加载 | 金额/列表骨架；不闪出0再加载真实金额 |
| 空态 | 一句原因+一个相关操作，不用大幅商业插画 |
| 金额显隐 | 全局遮盖；“显示金额/隐藏金额”读屏名称随状态改变 |
| 错误 | 描述问题与可执行恢复操作；不要只写“出错了” |
| 选中 | 色块+标记；分类图标辅助，文字必须保留 |
| 图表 | 有标题、范围、单位、数据明细；线型/标签辅助区分 |

读屏顺序跟视觉顺序一致。详情金额朗读为“支出，人民币22元”，图标重复语义时可隐藏。正文文字正常对比度目标至少4.5:1，大文字至少3:1；分隔线不承担唯一状态信息。分类颜色不用于表达正误。

## 7. 原型覆盖与使用

HTML可直接用浏览器打开，无网络依赖。左侧目录可以切换全部设计页；手机底部导航可点击，支持从明细进入详情、进入编辑记账、收支分类切换、自定义数字/加减键盘、保存演示记录、切换统计周期、月年账单与报告、预算设置、资产填写、分类管理与分享预览。

原型中的保存仅更新当前浏览器内存，刷新后重置。分享预览展示内容选择，不实际调用Android系统分享；备份恢复、删除撤销、真实统计聚合、分类排序等以PRD为实现要求，原型只呈现布局/状态，不能用于证明这些功能已实现。演示中的9月总额来自参考截图，部分行和预算/资产是样例，不保证样例列表相加等于截图总额；原型汇总有“参考快照”标识。生产版本必须由完整流水统一计算。

## 8. 设计验收清单

- 页面ID与PRD对应；每个主要入口有目标页，返回保留上下文。
- 360/390dp首屏能读到月结余、收支和最近流水；不被悬浮按钮遮挡最后一行。
- 类别网格、数字键盘、日期备注切换不遮住保存按钮。
- 表格金额右对齐，长备注省略，详情可读全文。
- 无记录、未设置、超支、失败和隐藏金额有独立文案。
- 大字号、320dp、横屏、手势安全区、读屏需在Android实现后实机验证。
- 原型使用系统字体，无外部图片/字体依赖；图标为统一代码绘制的线性图形。
