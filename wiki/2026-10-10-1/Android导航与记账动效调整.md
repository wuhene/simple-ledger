# Android 导航与记账动效调整

分支：`2026-10-10-1` · 更新：2026-10-10 · 状态：原生视觉对齐 Web 后待用户设备复验

## 用户反馈与验收目标

用户已在 Android 设备试用上一版 APK，提出以下四项调整；本需求只改原生 Android，Web 不参与本轮验收。

1. 底部导航的图标、文字和触控区域加大；中央“记一笔”比其余入口更醒目。
2. 四个主 Tab 去掉顶部说明和重复标题，包括“我的”及其上方的小字；内容上移。二级页面保留标题，帮助识别当前页面。
3. 主 Tab 点击后直接切换，不播放整页过渡动画。
4. 记账成功后，卡片向下滑出，露出的页面已是最新账目，不出现旧内容或整页淡入闪烁；取消和系统返回仍按原有下滑规则处理。

## 实现

- `project/android/app/src/main/java/com/wuhene/simpleledger/MainActivity.java`：底部导航拆成图标和文字两行，入口最小高度 80dp；中央入口使用 54dp 绿色按钮和更宽的布局。四个主页面移除顶部说明/标题并把内容顶部内边距降至 8dp。去掉整页淡入/位移动画。
- 记账成功时，在卡片完整覆盖页面期间同步刷新底层内容，随后让卡片下滑；动画结束后移除卡片并提示保存成功。取消时不刷新底层。系统关闭动画时即时显示最新页面。
- 用户再次反馈原生界面与 Web 版的视觉差异明显。本分支继续按已验收 Web 页面修正原生视觉：首页月选择使用白色描边按钮，汇总改为白色主卡与浅绿收支区；明细改为日期分组与独立行；移除首页额外预算卡，保留工具页预算入口；底部和分类图标改为原生 Canvas 绘制。工具、我的及下钻菜单加入图标块与箭头。
- 记账页改为支出/收入分段切换、最多两排的常用分类（可展开全部）、金额日期卡、独立保存按钮及与 Web 一致的数字键顺序。日期仍可从右下角“今天”键打开。输入备注时，数字键区随系统键盘隐藏，避免挤压输入区。
- `project/android/app/build.gradle` 与 `project/android/build-debug.ps1`：当前版本升为 `versionCode=3`、`versionName=0.1.2`，用于覆盖安装上一版。

## 设备复验清单

1. 覆盖安装 `project/android/SimpleLedger-debug.apk`，检查原有账本是否保留；建议更新前先导出 JSON 备份。
2. 在明细、统计、工具、我的四页检查底部按钮大小、中央入口突出程度、主内容上移、白色汇总卡和列表/菜单层次，以及 Tab 切换无过渡。
3. 从明细或统计打开记账，检查分类、金额日期、键盘和保存按钮的布局；输入备注时系统键盘应正常显示并恢复数字键区。新增/编辑一笔并完成：卡片下滑、底层账目或汇总已经更新、没有白闪或再次淡入。
4. 取消记账和系统返回仍下滑；有改动草稿时仍先提示是否放弃。小屏及系统大字号下检查底部五个入口与分类格是否可读、可点。
