# 简账 Web 二版验收版

本目录沿用 `wiki/2026-09-30-init/` 的业务规则，并实现 `wiki/2026-09-30-1/` 的二版视觉、日期选择和动效。它使用固定 390×844 手机画布，可切换为 360px。业务数据存于当前浏览器、当前地址的 IndexedDB；修改地址、端口或浏览器不会自动搬迁数据。

## 启动

需要 Node.js 20.3 或更高版本和现代浏览器。在本目录运行：

```powershell
npm start
```

打开 `http://127.0.0.1:4173/`。保持端口不变，以便重新打开时仍可读取同一个浏览器账本。无需安装 npm 依赖。运行业务规则测试：

```powershell
npm test
```

可从「我的 → 设置与数据」导出分月 ZIP 或兼容 JSON 备份。浏览器内的测试记录不会自动进入 Android App，当前 Android 只识别 JSON 内的账务字段。

## 代码

- `index.html`、`styles.css`：固定手机画布与界面。
- `app.js`：14 个页面、交互与报告图片。
- `model.js`：整数分金额、日期、统计及备份校验。
- `storage.js`、`ledger-search.js`、`ledger-rollups.js`：IndexedDB 读写、日期索引、全文检索和本地月汇总。
- `ledger-backup.js`：浏览器 Worker 内处理分月 ZIP、兼容 JSON 和分片校验。ZIP 使用随项目分发的 [fflate 0.8.3](licenses/fflate.txt)。
- `assistant.js`、`assistant-model.js`：AI 聊天、记账草稿、本地统计和识别结果校验。
- `assistant-bridge.js`：本机 Web 服务及模型请求中转。

明细、统计页右下角的悬浮按钮可打开 AI 助手。底栏中央「记一笔」先选择分类，再显示金额输入。通过「我的 → 设置与数据 → AI 助手设置」配置 API 地址、模型 ID 和 Key 并测试连接。聊天消息由该模型识别，账本统计在本机计算。设置在刷新前有效。点「新会话」开始新对话，点「历史」可恢复保存在当前浏览器中的旧会话。详见 [交互与技术方案](../../wiki/2026-11-24/AI助手-交互与技术方案.md)。

初版验收记录见 `../../wiki/2026-09-30-init/开发进度.md`。二版实现与验收状态见 `../../wiki/2026-09-30-1/实现与验收记录.md`；小屏、字体和性能补验见 `../../wiki/2026-10-09/进度与测试.md`。记账键盘右下角“日期”可直接打开日期选择器，在弹层中可选“今天”。原生工程和 APK 位于相邻的 `../android/`。
